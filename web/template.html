Riemann hypothesis Lean proof: tree of the source

Read this first. Built by static parse of the source (no Lean compile). Names are real Lean module paths; nothing here is written by an AI. Folders: "Depends on" counts import edges between modules, rolled up to the folder level. An import means may use, not does use. Proof route: an edge A → B means A's text mentions the name B, resolved with namespaces and open. It misses uses through dot-notation, structure fields, instances and notation, and can pick a wrong same-named declaration (0.5% of names are declared twice). Treat it as a map, not a proof. Counts come from keyword matching, so they are approximate. This view helps you navigate the proof. It does not verify it.
